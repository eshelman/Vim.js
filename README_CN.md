# Vim.js

为网页端 `textarea` 和 `input` 文本输入框打造的轻量级 Vim 按键绑定，提升网页端书写体验。

[在线演示](https://6by9.net/vimjs-demo/)

**注意：**

* 该项目不是为了在网页端替代强大的 IDE，而是作为网页端书写（如写博客、写笔记等）的增强功能。

* 请在英文输入法下使用 Vim 指令。

[English Documentation](README.md)

# 使用

```html
<script src="/path/to/vim.js"></script>
<script>
    vim.open({
        debug   : true,
        showMsg : function(msg){
            alert('vim.js say:' + msg);
        }
    });
</script>
```

# 开发与编译

```bash
# 安装依赖
npm install

# 开发模式（监听文件变化）
npm run dev

# 生产环境编译
npm run build

# 运行测试
npm test

# 监听模式运行测试
npm run test:watch
```

# 功能

## 一般模式

### 光标移动

| 指令 | 说明 |
| --- | --- |
| `h` 或 `Left` | 光标向左移动一个字符 |
| `j` 或 `Down` 或 `Enter` | 光标向下移动一行 |
| `k` 或 `Up` | 光标向上移动一行 |
| `l` 或 `Right` | 光标向右移动一个字符 |
| `0` 或 `Home` | 移动到当前行行首 |
| `$` 或 `End` | 移动到当前行行尾 |
| `w` / `W` | 移动到下一个词的词首 |
| `b` | 移动到上一个词的词首 |
| `B` | 移动到上一个大词的词首（以空白符分隔） |
| `e` | 移动到当前词的词尾 |
| `E` | 移动到当前大词的词尾（以空白符分隔） |
| `gg` | 跳转到第一行 |
| `G` | 跳转到最后一行 |
| `f{字符}` | 向前查找字符（移动到该字符） |
| `F{字符}` | 向后查找字符 |
| `t{字符}` | 向前移动到字符之前（不含该字符） |
| `T{字符}` | 向后移动到字符之后 |
| `;` | 按相同方向重复上次 `f`/`F`/`t`/`T` |
| `,` | 按相反方向重复上次 `f`/`F`/`t`/`T` |
| `(` | 移动到上一个句子 |
| `)` | 移动到下一个句子 |
| `{` | 移动到上一个段落 |
| `}` | 移动到下一个段落 |

所有移动指令支持数字前缀（例如 `3w`、`5j`、`2f{字符}`）。

### 搜索

| 指令 | 说明 |
| --- | --- |
| `/{查询}` | 向前搜索文本 |
| `?{查询}` | 向后搜索文本 |
| `n` | 按相同方向重复上次搜索 |
| `N` | 按相反方向重复上次搜索 |
| `*` | 向前搜索光标下的单词 |
| `#` | 向后搜索光标下的单词 |

### 删除、复制与粘贴

| 指令 | 说明 |
| --- | --- |
| `x` 或 `Delete` | 删除光标处的字符 |
| `X` | 删除光标前的字符 |
| `dd` | 删除当前行 |
| `dw` | 向前删除一个词 |
| `db` | 向后删除一个词 |
| `df{字符}` | 删除到下一个指定字符处（含该字符） |
| `dF{字符}` | 删除到上一个指定字符处（含该字符） |
| `dt{字符}` | 删除到下一个指定字符之前（不含该字符） |
| `dT{字符}` | 删除到上一个指定字符之后（不含该字符） |
| `yy` | 复制当前行 |
| `yw` | 向前复制一个词 |
| `yb` | 向后复制一个词 |
| `yf{字符}` | 复制到下一个指定字符处（含该字符） |
| `yF{字符}` | 复制到上一个指定字符处（含该字符） |
| `yt{字符}` | 复制到下一个指定字符之前（不含该字符） |
| `yT{字符}` | 复制到上一个指定字符之后（不含该字符） |
| `p` | 在光标后粘贴 |
| `P` | 在光标前粘贴 |

删除和复制指令支持数字前缀（例如 `3dd`、`2dw`）。

### 文本对象

文本对象可与删除（`d`）、复制（`y`）和修改（`c`）操作符配合使用：

| 指令 | 说明 |
| --- | --- |
| `diw` / `daw` | 删除词内部 / 删除整个词（含周围空格） |
| `ciw` / `caw` | 修改词内部 / 修改整个词 |
| `yiw` / `yaw` | 复制词内部 / 复制整个词 |
| `di"` / `da"` | 删除双引号内部 / 删除含双引号 |
| `di'` / `da'` | 删除单引号内部 / 删除含单引号 |
| `di(` / `da(` | 删除圆括号内部 / 删除含圆括号 |
| `di{` / `da{` | 删除花括号内部 / 删除含花括号 |
| `di[` / `da[` | 删除方括号内部 / 删除含方括号 |

`ci` 和 `yi` 系列指令以相同方式配合对应的操作符使用。

### 修改（删除并进入编辑模式）

| 指令 | 说明 |
| --- | --- |
| `cc` | 修改整行 |
| `cw` | 向前修改一个词 |
| `cb` | 向后修改一个词 |
| `C` | 从光标处修改到行尾 |
| `s` | 替换字符（删除并进入编辑模式） |
| `S` | 替换整行（同 `cc`） |

### 撤销、重做与重复

| 指令 | 说明 |
| --- | --- |
| `u` | 撤销（支持多级撤销） |
| `Ctrl+R` | 重做 |
| `.` | 重复上次编辑指令 |

撤销以编辑会话为单位：在编辑模式中输入的内容作为一个整体被撤销，而非逐字符撤销。撤销后的新编辑操作会清除重做历史（与 Vim 行为一致）。

## 编辑模式

| 指令 | 说明 |
| --- | --- |
| `i` | 在光标处插入 |
| `I` | 在当前行行首插入 |
| `a` | 在光标后追加 |
| `A` | 在当前行行尾追加 |
| `o` | 在下方新建一行并进入编辑模式 |
| `O` | 在上方新建一行并进入编辑模式 |
| `r` | 替换光标处的字符 |
| `Esc` | 返回一般模式 |

## 视图模式

| 指令 | 说明 |
| --- | --- |
| `v` / `V` | 切换到视图模式（字符选择） |
| `y` | 复制选中的文本 |
| `x` / `d` | 删除选中的文本 |
| `c` | 修改选中的文本（删除并进入编辑模式） |

在应用操作符之前，可使用任意移动指令来扩展选区。
